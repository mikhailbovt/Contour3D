# Support

Contour3D is maintained by **Mikhail Bovt**.

- Report a reproducible bug or request a feature in [GitHub Issues](https://github.com/mikhailbovt/Contour3D/issues).
- For a privacy or licensing concern, open an issue with a brief description and no confidential attachments. The maintainer is [Mikhail Bovt](https://github.com/mikhailbovt).

For a useful bug report, include the Contour3D version, operating system, Blender version, Codex client version, the task you attempted and the relevant error. If a small reproduction is needed, use an original or appropriately licensed example that contains no private information.

Reports and renders can contain local paths, scene names and metadata. Review and redact them before sharing. Do not upload credentials, private models, customer assets or proprietary references to a public issue.

Support is provided on a best-effort basis, without a guaranteed response time. See [privacy](PRIVACY.md), [terms](TERMS.md) and [verification limits](https://github.com/mikhailbovt/Contour3D/blob/main/docs/verification.md).
